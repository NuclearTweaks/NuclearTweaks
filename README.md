# NuclearTweaks

Jailbreak tweaks for iOS 27 — developed against a jailbroken simulator, shipped
rootless for when the real thing lands.

**Repo (Sileo/Cydia): `https://nucleartweaks.github.io/`**

| Repo | Role |
|---|---|
| `.github` | shared CI (reusable tweak-ci: build → release PR → publish) |
| `NuclearTweaks.github.io` | APT repo served by Pages |
| `meta` | knowledge base + workspace tools (KB is the brain — read `knowledge/pitfalls.md`) |
| per-tweak repos | one Theos project each, topic `nucleartweaks-tweak` |
